Training is a search for parameters that make a loss small. Gradient descent
takes the cheapest available step towards that: move against the gradient, by
an amount the learning rate sets.

$$
\theta_{t+1} = \theta_{t} - \eta \, \nabla_{\theta} L(\theta_{t})
$$

The learning rate $\eta$ is the whole drama. Too small and the loss creeps down
over more steps than anyone will wait for; too large and each step overshoots
the minimum it was aiming at, and the loss climbs instead.

## The loop

```python
def descend(theta, grad, learning_rate=0.1, steps=100):
    """Plain gradient descent, with no momentum and no schedule."""
    for _ in range(steps):
        theta = theta - learning_rate * grad(theta)
    return theta
```

## Take the steps yourself

The demonstration minimizes $f(x) = x^{2}$, whose gradient is $2x$, so one step
is exactly $x \leftarrow x(1 - 2\eta)$ — and the whole behaviour of the run is
decided by how large $|1 - 2\eta|$ is.

| Learning rate | $\lvert 1 - 2\eta \rvert$ | Behaviour                          |
| ------------- | -------------------------- | ---------------------------------- |
| `0.05`        | 0.9                        | converges, one slow step at a time  |
| `0.50`        | 0                          | lands on the minimum in one step    |
| `0.90`        | 0.8                        | overshoots, alternates, converges   |
| `1.05`        | 1.1                        | overshoots by more each time        |
