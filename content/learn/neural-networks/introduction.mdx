A feed-forward network is a stack of affine maps with a nonlinearity between
them. One layer is a matrix multiply, a bias, and a function applied
element-wise:

$$
h = \sigma(W x + b)
$$

Stack two of those and the network can represent something a single affine map
cannot — which is the entire reason the nonlinearity is there.

## The smallest version

```python
import numpy as np


def layer(x: np.ndarray, w: np.ndarray, b: np.ndarray) -> np.ndarray:
    """One affine map followed by a nonlinearity."""
    return np.maximum(0.0, x @ w + b)
```
