Without a nonlinearity, a stack of layers collapses: $W_2(W_1 x) = (W_2 W_1) x$
is a single affine map however many layers were stacked. The activation is what
stops the collapse.

## The usual three

$$
\operatorname{ReLU}(z) = \max(0, z)
\qquad
\sigma(z) = \frac{1}{1 + e^{-z}}
\qquad
\tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}}
$$

ReLU's derivative is $1$ for positive inputs and $0$ elsewhere, so it neither
shrinks nor grows the gradient it passes back. The sigmoid's derivative peaks
at $0.25$ and approaches zero at both tails, which is the vanishing-gradient
story in one line.

```typescript
type Activation = (z: number) => number;

const relu: Activation = (z) => Math.max(0, z);
const sigmoid: Activation = (z) => 1 / (1 + Math.exp(-z));
const tanh: Activation = Math.tanh;
```

derivative together. That demonstration arrives with the interactive components.
