Attention is a weighted average over values, where the weights come from how
well a query matches each key:

$$
\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\left(\frac{Q K^{\top}}{\sqrt{d_k}}\right) V
$$

The $\sqrt{d_k}$ divisor keeps the logits from growing with the key dimension,
which would otherwise push the softmax towards a one-hot and flatten the
gradient.

## In code

```python
import numpy as np


def attention(q: np.ndarray, k: np.ndarray, v: np.ndarray) -> np.ndarray:
    scores = q @ k.T / np.sqrt(k.shape[-1])
    weights = np.exp(scores - scores.max(axis=-1, keepdims=True))
    weights /= weights.sum(axis=-1, keepdims=True)
    return weights @ v
```
