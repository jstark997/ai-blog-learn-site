Scaled dot-product attention is a weighted average over values, where the
weights come from the compatibility of a query with each key:

$$
\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\left(\frac{Q K^{\top}}{\sqrt{d_k}}\right) V
$$

The $\sqrt{d_k}$ term keeps the logits from growing with the key dimension, so
the softmax does not saturate.

## In code

```python
import numpy as np


def attention(q: np.ndarray, k: np.ndarray, v: np.ndarray) -> np.ndarray:
    """Single-head scaled dot-product attention."""
    scores = q @ k.T / np.sqrt(k.shape[-1])
    weights = np.exp(scores - scores.max(axis=-1, keepdims=True))
    weights /= weights.sum(axis=-1, keepdims=True)
    return weights @ v
```

## Shapes

| Tensor | Shape          | Role                          |
| ------ | -------------- | ----------------------------- |
| `Q`    | `(n, d_k)`     | what each position is asking   |
| `K`    | `(m, d_k)`     | what each position offers      |
| `V`    | `(m, d_v)`     | what is averaged               |
